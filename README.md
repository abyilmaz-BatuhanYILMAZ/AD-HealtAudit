# AD-HealthAudit — Live, read-only AD security indicators

A Windows PowerShell 5.1+ utility that connects to an authorized live Active Directory Domain Services domain and reports security-relevant user, computer, delegation, Kerberos encryption and password-policy indicators. No directory state changes are made.

The source code, risk documentation and automated tests are included in this repository. **Actual Domain Controller verification is still required.**
